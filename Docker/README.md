# 🐳 Containerization with Docker

This directory contains tasks, labs, and exercises completed for the **Docker** module of the NTI training program.

---

## Completed Labs

| Lab | Description | Documentation |
| :--- | :--- | :--- |
| **Lab 3** | Creating a Docker image for a Java application using two approaches (building inside Docker with Maven vs. building locally with JRE), non-root user setup, and image size comparison. | [Lab 3 Documentation](Lab3/README.md) |
| **Lab 4** | Docker Image Optimization (Multi-stage build, non-root user security, image size reduction) and Image Export/Load (`docker save` & `docker load`). | [Lab 4 Documentation](Lab4/README.md) |
| **Lab 5** | Docker Image Vulnerability Scanning with Trivy, filtering HIGH & CRITICAL CVEs, HTML reporting, and complete Vulnerability Remediation with non-root Alpine runtime. | [Lab 5 Documentation](Lab5/README.md) |
| **Lab 6** | Docker Environment Variables (CLI `-e`, `--env-file`, Dockerfile `ENV`) and Resource Management (`--cpus`, `--memory`, `docker stats`). | [Lab 6 Documentation](Lab6/README.md) |
| **Lab 7** | Multi-Network Microservices (custom bridge networks, dual-homed backend), named volumes (`backend-logs`, `notification-logs`), and host bind mounts. | [Lab 7 Documentation](Lab7/README.md) |
| **Lab 8** | Containerized Node.js and MySQL Stack Using Docker Compose, multi-container networking (`ivolve-net`), persistent volumes, and Docker Hub distribution. | [Lab 8 Documentation](Lab8/README.md) |
