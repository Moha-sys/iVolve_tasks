# GitOps Module

Welcome to the **GitOps Module** of the iVolve Training Program.

## Labs in this Module

- [Lab 23: Implementing a GitOps Workflow with Jenkins and Argo CD](Lab23/README.md)
  - Argo CD Installation & NodePort configuration on Kubernetes
  - Connecting GitHub Repository to Argo CD
  - Creating Argo CD Application `ivovle` with automated synchronization and self-healing
  - Enhancing Jenkins Shared Library `DeployOnK8s` role to commit and push manifest updates to Git
  - Executing end-to-end CI/CD GitOps workflow from Jenkins pipeline build to Argo CD cluster rollout
