# 🔄 Continuous Integration & Continuous Delivery (CI/CD) with Jenkins

This directory contains tasks, configurations, automation scripts, and verification guides for the **Jenkins** CI/CD module of the NTI training program.

---

## Completed Labs

| Lab | Description | Documentation |
| :--- | :--- | :--- |
| **Lab 20** | Role-based Authorization in Jenkins: user management (`user1`, `user2`), global roles (`admin`, `read-only`), assignment, and permission verification. | [Lab 20 Documentation](Lab20/README.md) |
| **Lab 21** | Jenkins Pipeline for Application Deployment: 7-stage CI/CD pipeline building Spring Boot app, Docker build, Trivy scan, Docker Hub push, local cleanup, manifest update, and Kubernetes cluster rollout. | [Lab 21 Documentation](Lab21/README.md) |
| **Lab 22** | CI/CD Pipeline Implementation with Jenkins Agents and Shared Libraries: reusable shared library (`BuildApp`, `BuildImage`, `DeployOnK8s`), distributed inbound agent (`slave-node`), and automated K8s continuous delivery. | [Lab 22 Documentation](Lab22/README.md) |
